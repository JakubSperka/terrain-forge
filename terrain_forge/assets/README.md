# Terrain Forge icon

`terrain-forge.png` was generated using the built-in image generation tool and is used for the window/taskbar icon and application header.

`terrain-forge.ico` is the 256-pixel Windows icon derived from that image for the launcher shortcut.

Prompt: Use case: logo-brand. Create a polished Windows desktop application icon for Terrain Forge, a tool converting elevation maps into multicolor 3D printed terrain. Single centered bold isometric square terrain slab with a sculpted mountain peak, layered contour bands and a simple blue river inlay. Clear chunky silhouette readable at 32 pixels, minimal detail, premium clean stylized 3D illustration. Earth and forest tones with bright blue river, subtle shading, no text, no letters, no surrounding scene. Transparent background, ample small padding, square composition. Intended as an actual app icon, not a mockup.
